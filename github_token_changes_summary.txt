GitHub Token Integration Change Log
===================================

Purpose
-------
Enable the pipeline to use GitHub Models (token-based auth) as an LLM provider
across orchestrator and all specialist agents.

Flow of changes
---------------
1) Config layer was updated to introduce GitHub provider settings.
2) Dependency layer was updated to support OpenAI-compatible GitHub Models calls.
3) Orchestrator LLM factory was updated to route to GitHub Models.
4) Each specialist agent LLM factory was updated so every phase can use the same provider.

Detailed file-by-file changes
-----------------------------

1) core/config.py

- Added explicit provider selection:
  LLM_PROVIDER = "github"
  GITHUB_MODEL = os.getenv("GITHUB_MODEL")
  GITHUB_TOKEN = os.getenv("GITHUB_TOKEN")

Why this matters:
- Centralizes provider switch to GitHub mode.
- Makes all downstream components read token/model from environment.

2) requirements.txt: Add below dependency

'''
langchain-openai>=0.1.0
'''

Why this matters:
- ChatOpenAI client is required for OpenAI-compatible endpoint usage.
