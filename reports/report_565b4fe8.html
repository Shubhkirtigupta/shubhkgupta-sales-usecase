📊 Approach & Query

Query Code


-- Create complete dataset for HTML report generation
WITH product_aggregated AS (
  SELECT 
    join_key_product,
    product_name,
    MAX(standard_price) AS standard_price,
    SUM(filter_positive_sales) AS total_units_sold,
    SUM(total_revenue) AS total_revenue,
    SUM(transaction_count) AS total_transactions,
    MAX(store_count) AS stores_reached,
    ROUND(SUM(total_revenue) / NULLIF(SUM(filter_positive_sales), 0), 2) AS avg_revenue_per_unit,
    ROUND(SUM(total_revenue) - (SUM(filter_positive_sales) * MAX(standard_price)), 2) AS estimated_profit,
    ROUND((SUM(total_revenue) - (SUM(filter_positive_sales) * MAX(standard_price))) / NULLIF(SUM(total_revenue), 0) * 100, 2) AS profit_margin_pct
  FROM best_performing_products
  WHERE filter_positive_sales IS NOT NULL AND filter_positive_sales > 0
  GROUP BY join_key_product, product_name
),
ranked AS (
  SELECT 
    *,
    ROW_NUMBER() OVER (ORDER BY total_revenue DESC) AS rank
  FROM product_aggregated
)
SELECT 
  rank,
  product_name,
  '$' || ROUND(standard_price, 2) AS std_price,
  total_units_sold AS units,
  '$' || ROUND(total_revenue, 2) AS revenue,
  '$' || ROUND(estimated_profit, 2) AS profit,
  profit_margin_pct || '%' AS margin,
  stores_reached AS stores,
  total_transactions AS transactions
FROM ranked
ORDER BY rank
LIMIT 15

Query Description

SQL query aggregated product performance data by join_key_product and product_name, calculating total_revenue, total_units_sold, estimated_profit (revenue minus cost basis using standard_price × units), profit_margin_percentage, transaction counts, and store reach. Products were ranked using ROW_NUMBER() window functions across three dimensions: revenue, units sold, and profit. The analysis identified that while some products like TRX Resistance Bands sold the most units (64), premium electronics delivered significantly higher revenue and profit contribution.
